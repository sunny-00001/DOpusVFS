## 最有价值的资源（按重要性排序）

### 1. PretentiousName 插件源码 ⭐⭐⭐⭐⭐
**位置**：`PretentiousName/PNOpusPlugins_2009-08-03/`  
**作者**：Leo Davidson（Opus 团队成员）

这是学习 Directory Opus 插件开发的最佳教材！包含：

#### common/ 目录（必看！）
- **plugin support.h** - 插件支持头文件（从 SDK 来的）
- **viewer plugins.h** - 查看器插件头文件
- **vfs plugins.h** - VFS 插件头文件
- **LeoHelpers.cpp/h** - 常用帮助类
- **Win32IOWrapper.cpp/h** - 文件/流 IO 包装类（流处理参考）
- **messages.hpp** - 消息定义
- **plugindialogs.h** - 插件对话框

#### 各插件源码
1. **nfo/** - NFO 查看器 ⭐⭐⭐⭐⭐（新手最佳入门）
   - 最简单的自定义窗口查看器
   - 基于子类化编辑控件
   - 流支持

2. **targa/** - TGA 图像查看器 ⭐⭐⭐⭐
   - 支持 Alpha 通道、预乘 Alpha 等
   - 模板元编程优化
   - 对比 SDK 示例学习

3. **textthumb/** - 文本缩略图 ⭐⭐⭐⭐
   - 仅缩略图插件示例
   - 动态重新生成缩略图
   - 进程范围缓存 + 管理线程
   - XML 配置文件

4. **audiotags/** - 音频标签 ⭐⭐⭐⭐
   - 文件信息 + 缩略图插件
   - 直接 I/O 流处理
   - 多格式支持

5. **gifanim/** - GIF 动画 ⭐⭐⭐
   - 完整功能查看器
   - 自定义工具栏、菜单
   - 动画支持

6. **dcrawrap/** - RAW 相机 ⭐⭐⭐
   - 复杂的真实世界示例
   - 线程安全改造

## 学习路径建议

### 新手入门
1. 先看 `PretentiousName/nfo/` - 最简单的查看器
2. 再看 `PretentiousName/targa/` - 简单图像查看器

## 关键技术要点总结

### VFS 插件要点
- 实现 VFS_Check, VFS_FindFirst/Next/Close, VFS_Open/Read/Write/Close
- 支持 URL 格式路径
- 提供 32 位和 64 位版本

### 查看器插件要点
- 两种方式：返回 HBITMAP 或创建自定义窗口
- 流支持（处理归档内文件）
- 配置对话框（可选）

### 通用要点
- Unicode 支持（WCHAR）
- USB 模式支持（配置不存注册表）
- 线程安全
- 正确的资源管理
