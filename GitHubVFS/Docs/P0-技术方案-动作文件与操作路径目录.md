## 二、数据结构变更

### 2.1 GitHubMetaType 枚举扩展

在现有枚举末尾追加：

```cpp
GITHUB_META_ACTION_STAR,          // .gh/star/
GITHUB_META_ACTION_UNSTAR,        // .gh/unstar/
GITHUB_META_ACTION_WATCH,         // .gh/watch/
GITHUB_META_ACTION_UNWATCH,       // .gh/unwatch/
GITHUB_META_ACTION_DOWNLOAD_ZIP,  // .gh/download-zip/
GITHUB_META_ACTION_DOWNLOAD_TAR,  // .gh/download-tar/
GITHUB_META_ACTION_CLONE_URL      // .gh/clone-url/
```

### 2.2 VirtualFileType 枚举（新增）

```cpp
enum VirtualFileType {
    VIRTUAL_FILE_NONE = 0,
    VIRTUAL_FILE_DOWNLOAD_ZIP,
    VIRTUAL_FILE_DOWNLOAD_TAR,
    VIRTUAL_FILE_CLONE_URL,
    VIRTUAL_FILE_RESULT_TEXT
};
```

### 2.3 GitHubContentInfo 结构体扩展

新增字段 `VirtualFileType virtualType;`

## 三、函数改造详细设计

### 3.1 ParseGitHubPath

在 `if (metaSeg == L"releases")` 分支之后、`info.metaItem = metaSeg` 兜底之前插入 7 个操作目录解析。

- star/unstar/watch/unwatch：纯操作目录，无子文件
- download-zip/download-tar：操作目录 + 子文件（owner-repo.zip / owner-repo.tar.gz）
- clone-url：操作目录 + 子文件（clone-url.txt）

### 3.2 ReadMetadataDirectory

**GITHUB_META_ROOT**：从 10 项扩展到 18 项（5 已有目录 + 7 操作目录 + 6 虚拟文件）

**新增 7 个 metaType 处理**：
- GITHUB_META_ACTION_STAR/UNSTAR/WATCH/UNWATCH：调用 API → 返回结果文件
- GITHUB_META_ACTION_DOWNLOAD_ZIP/TAR：返回虚拟 ZIP/TAR.GZ 文件
- GITHUB_META_ACTION_CLONE_URL：返回 clone-url.txt

### 3.3 VFS_CreateFileW

在 `DownloadFile` 调用前增加 `isVirtualFile` 判断分支：
- GITHUB_META_ACTION + metaItem：download-zip/tar/clone-url
- GITHUB_META_ACTION_DOWNLOAD_ZIP/TAR/CLONE_URL + metaItem：子文件
- GITHUB_META_ACTION_STAR/UNSTAR/WATCH/UNWATCH：结果文件
- GITHUB_META_SIGNAL/MIRROR：P0 占位内容

### 3.4 VFS_CloseFile

虚拟文件（virtualType != VIRTUAL_FILE_NONE）跳过上传逻辑。

### 3.5 VFS_GetFileInformationW

虚拟文件直接返回文件名 + READONLY 属性，不调用 GetFileInfo。

### 3.6 VFS_DeleteFileW / VFS_RenameFileW

isVirtualFile 为 true 时返回 FALSE。

### 3.7 VFS_GetPathDisplayNameW

新增 7 个 metaType 的中文显示名。

## 四、数据流

```
导航 .gh/star/ → ReadDirectory → StarRepo API → 返回 [✓ 已星标.txt]
打开 ✓ 已星标.txt → CreateFileW(虚拟分支) → 生成文本 → ReadFile → 返回
```

```
导航 .gh/download-zip/ → ReadDirectory → 返回 [owner-repo.zip]
复制 owner-repo.zip → CreateFileW(虚拟分支) → DownloadArchive → ReadFile → 返回 ZIP 数据
```

## 五、风险与缓解

| 风险 | 缓解措施 |
|------|----------|
| 大文件内存占用 | P0 先用内存方案，后续改流式 |
| 重复导航触发重复 API | GitHub API 幂等；后续加缓存标记 |
| download.tar.gz 路径拆分 | 无中间 `/`，不会被拆分 |

## 六、实现顺序

1. GitHubClient.h（枚举+结构体）
2. ParseGitHubPath（7个操作目录解析）
3. ReadMetadataDirectory（目录读取）
4. VFS_CreateFileW（虚拟文件内容生成）
5. VFS_CloseFile（跳过上传）
6. VFS_GetFileInformationW（虚拟文件信息）
7. VFS_DeleteFileW / VFS_RenameFileW（禁止操作）
8. VFS_GetPathDisplayNameW（显示名）
