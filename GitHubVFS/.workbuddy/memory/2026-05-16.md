## 第二轮审查修复（2026-05-16 17:00）

### 发现的 Bug 和修复

#### 严重 Bug
1. **前向声明位置错误**：辅助函数声明在 `GitHubPathInfo` 定义之前，导致编译器无法识别类型。修复：将声明移到结构体定义之后。
2. **多余的闭合括号**：第 440 行有多余的 `}`，删除。
3. **辅助函数无边界检查**：`ResolveFlatRepo(segs[1])`、`ParseRepoSubdir(segs[offset])`、`ParseRefSyntax(segs[offset])` 未检查越界。修复：各函数内添加防御检查。
4. **`metaItem` 从未被设置**：Gists/{id}/ 和 Notifications/{id}/ 子路径信息丢失。修复：在 `ParseRootPath` 中添加 Gists/Notifications 子路径处理。
5. **Gists/Notifications 子路径完全未处理**：`Gists/{gistId}/` 和 `Notifications/{id}/` 无法解析。修复：添加子路径处理逻辑和 page:N 支持。

#### 中等 Bug
6. **`page:N` 在非搜索路径中不生效**：Repos/page:2/、Starred/page:2/、owner/page:2/ 等无法翻页。修复：在各路径解析函数中添加 page:N 检查。
7. **`int` vs `size_t` 类型安全问题**：`JoinPathSegments`、`ParseRepoSubdir`、`ParseRefSyntax` 的 offset 参数从 `int` 改为 `size_t`。
8. **ParseQueryString URL 解码不完整**：不处理 `+` 空格、%00 null byte、参数边界匹配不精确。修复：重写查询字符串解析，按 & 分割后精确匹配参数名，添加 + 解码和 %00 防护。
9. **Search 子路径重定向缺失**：Search/Code、Search/Commits 无法重定向到仓库。修复：添加重定向规则。
10. **Releases/{tagName}/ 子路径未处理**：`ParseRepoSubdir` 中 Releases 缺少子路径解析。修复：添加处理逻辑。
11. **Code 子路径 isDir 语义**：Code 下的所有子路径都被标记为 isDir=true，文件也是。改进：将 Code 分支提前处理，路径交由 ListDirectory 判断。
12. **ParsePageSegment 使用 substr 比较**：改为 `compare()` 避免临时字符串分配。
13. **GetOwnerContextType 用 if-else**：改为 unordered_map 查找表，与其他查找表一致。
