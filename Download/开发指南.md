# Directory Opus 插件开发指南

## SDK 获取

### 官方 SDK 下载
从 GPSoftware 官方支持页面下载 SDK：
- https://support.gpsoft.com.au/download

SDK 包含：
- 头文件（opusplug.h, plugin support.h, vfs plugins.h, viewer plugins.h）
- 库文件
- 文档（modules.doc, hooks.doc）
- 示例代码

## 插件类型

### 1. VFS 插件（虚拟文件系统）
用于支持新的归档格式或虚拟文件系统。
**导出函数**：
- VFS_Check - 检查是否支持该文件/路径
- VFS_FindFirst, VFS_FindNext, VFS_FindClose - 枚举目录内容
- VFS_Open, VFS_Read, VFS_Write, VFS_Close - 文件操作
- 等等...

### 2. 查看器插件
用于预览特定文件类型。
有两种方式：
- 简单方式：返回 HBITMAP
- 高级方式：创建自定义窗口

### 3. 文件信息插件
提供文件元数据信息。

### 4. 缩略图插件
生成文件缩略图。

## 重要开发技术

### 流处理（Streams）
有两种方式处理流：
1. **直接 I/O 方式**：直接从流读取数据
   - 适合顺序读取
   - 参考：Audio Tags 插件
2. **临时文件方式**：提取到临时文件后操作
   - 适合随机访问
   - 更简单但可能较慢

### Unicode 支持
- 使用宽字符（WCHAR）
- 安全的字符串转换
- 文件路径使用 Unicode

### USB 模式支持
- 插件需要明确声明支持 USB 模式
- 配置数据应存储在插件目录或 XML 文件中，而非注册表
- 32 位和 64 位版本都需要提供

### 线程安全
- Opus 可能多线程调用插件
- 使用临界区（CRITICAL_SECTION）同步
- 避免使用全局/静态变量，或正确保护它们

## 开发环境设置

### 推荐工具
- Visual Studio 2019 或更高版本
- Windows SDK

### 项目配置
- 输出类型：动态链接库（DLL）
- 字符集：Unicode
- 运行库：多线程（/MT）或多线程 DLL（/MD）
- 同时构建 Win32 和 x64 版本

### DEF 文件
需要创建 .def 文件导出函数：
```
LIBRARY "MyPlugin"
EXPORTS
    OpusPluginInfo
    VFS_Check
    VFS_FindFirst
    VFS_FindNext
    VFS_FindClose
    VFS_Open
    VFS_Read
    VFS_Write
    VFS_Close
```
